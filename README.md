## Vertical and HDR Editing Overview

This independent guide covers post-production after a console recording is already on your drive. A vertical timeline lets you set a 9:16 frame and decide what to crop, reposition, or leave visible in each shot. HDR is a separate delivery decision: check whether the original recording actually preserved HDR before choosing an output format.

Create the portrait edit from a copy of your landscape timeline so the original composition stays intact. Reframe around the subject and watch for important captions or interface elements disappearing at the edges. For HDR, identify the source’s color space and transfer function, then check the output on an HDR-capable display and in a compatible player.

The app ships in two builds: the standard build covers grading and HDR tools, while the Studio build adds features such as Smart Reframe and advanced HDR formats. Check the current codec list for your OS, bit depth and build before choosing one. When reading reports, look for footage and hardware like yours, or compare a simpler editor if you mostly need cuts and captions.

## Getting Started Playbook

Install the edition you intend to use and import a short sample of the same recording format as your real footage. For portrait delivery, set a vertical resolution such as 1080 × 1920 and confirm the intended timeline frame rate before editing. Use the Inspector to adjust framing shot by shot and leave space for subtitles or platform overlays.

For HDR, verify how the capture was recorded and assign the correct input color space if needed. Set the output color space and select a supported codec, bit depth, and tagging combination appropriate for the destination. Render a short sample and verify both the reported metadata and playback before exporting the complete timeline.

## Everyday Use

The desktop app can edit local projects without a Blackmagic Cloud login; cloud collaboration is a separate workflow. Use Edit features for cuts and reframing, Color for the grade, and Deliver to queue the export. Label separate SDR and HDR versions clearly so the wrong master does not end up in the upload queue.

## Troubleshooting Common Issues

Install issues? Check installer architecture, supported OS version, and required GPU driver before reinstalling.  
Performance problems? Generate proxies for demanding footage, lower timeline playback resolution, and check available cache space.  
Edition differences? The app ships in two builds; the Studio build is the one that adds Dolby Vision and HDR10+ delivery.  
Compatibility? If a clip is offline or an export option is missing, check the exact codec, profile, bit depth, OS, and edition against the supported codecs list.  
Update failures? Back up projects and the project library, then consult the release notes for driver and migration requirements before retrying.
